# 팀 일정 현황판 요구사항

- 팀원: 김하늘, 이도윤, 박서연, 최민준 (4명)
- 데이터: `public/data/schedule.json` (가상 데이터)
- 공유: 공유 링크로 브라우저에서 열람

## 1. 목적
- 팀원이 아침마다 한 화면에서 팀 전체 일정과 기한을 확인한다.
- 담당자별로 걸러 보며 자기 일을 빠르게 찾는다.
- 지연된 일정을 눈에 띄게 드러내 먼저 챙기게 한다.

## 2. 화면
단일 페이지(`index.html`), PC와 휴대폰에서 모두 사용 가능.

1. **상단**: 페이지 제목, 오늘 날짜
2. **담당자 필터**: 드롭다운 — `전체`(기본값), 김하늘, 이도윤, 박서연, 최민준
3. **일정 표**: 열은 `일정`, `담당자`, `기한`, `상태`
   - 기한이 빠른 순서로 정렬
   - 상태가 `지연`인 행은 배지와 색으로 강조 (색만으로 구분하지 않고 글자도 표시)
4. 필터 결과가 없거나 데이터 로드에 실패하면 안내 문구 표시
5. 표시 문구는 한국어

## 3. 데이터
- 위치: `public/data/schedule.json`
- 구조(안):

  ```json
  {
    "items": [
      { "id": 1, "title": "주간 보고서 작성", "assignee": "김하늘",
        "due": "2026-10-16", "status": "진행" }
    ]
  }
  ```

- `status` 값: `예정`, `진행`, `완료`, `지연` (파일에 저장된 값을 그대로 표시)- 가상 데이터 구성 (완료 기준과 맞춤):
  - 총 12건
  - 담당자별 3건씩 (김하늘 3, 이도윤 3, 박서연 3, 최민준 3)
  - `지연` 3건
  - 기한은 모두 서로 다른 날짜로 두어 정렬 결과가 하나로 정해지게 함

## 4. 완료 기준
1. 표의 행 수가 12이다.
2. 담당자 필터에서 김하늘을 고르면 3행만 보인다.
3. '지연' 표시는 3건이다.
4. 기한이 빠른 순서로 정렬된다.

## 5. 만들지 않는 것

- 일정 추가와 수정
- 서버 저장
